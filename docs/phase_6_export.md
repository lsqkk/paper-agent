# 阶段六：导出Word文档

## 前置准备

读取 `report_revised.md`，确认用户已回复"定稿"。

## 执行步骤

### 1. 字数裁剪（按需）

检查 `report_revised.md` 字数。如果超过任务要求字数的110%，进行裁剪：
- 保留核心论证，删减冗余表述
- 裁剪后保存为 `report_final.md` 用于导出
- 未超限则直接用 `report_revised.md` 导出

### 2. 图片处理

默认直接导出SVG。仅当用户明确要求PNG位图时执行SVG→PNG转换（Chrome headless 2x DPI截图 + Pillow裁剪白边）。

### 3. md2docx 转换

使用内置的学术论文模板将Markdown转为Word文档。

### 4. 保存

若用户未指定导出路径，保存到仓库根目录，文件名为 `【任务要求.md中的标题】_最终报告.docx`。
若用户指定了路径，则按指定路径保存。

### 5. 完成标记

输出：
```
✅ 报告已生成：[完整路径]
```

并简要总结：
- 报告总字数
- 图片数量
- 参考文献条数
