# 阶段三：正式写作

## 前置准备

读取以下文件：
- `初步大纲.md`（目录结构和字数预算）
- `collected_info.md`（信息条目，含引用编号）
- `docs/workflow_rules.md`（六项文风规范）

## 策略

采用"分段写作、逐节压缩、最后组装"的策略，避免单次超长写作导致质量退化。

---

### 3a. 写作规划

分析大纲将二级标题分为两类：

| 类型 | 特征 | 示例 |
|------|------|------|
| 核心论述章 | 需要充实验证的主体内容 | 文献综述、方法、分析、讨论 |
| 包装章 | 引用核心章节内容 | 引言、摘要、结论 |

**写作顺序**：核心论述章按大纲顺序先写 → 包装章最后写

---

### 3b. 逐节写作核心论述章

对每个核心论述章执行以下循环：

**准备上下文**：
- 从 `collected_info.md` 中提取与该章节直接相关的条目（通过"对应大纲章节"字段筛选）
- 读取 `_writing_log.md` 获取所有已写章节的压缩摘要
- 回顾字数预算表中该章节的目标字数

**写作**：
- 严格遵守 `docs/workflow_rules.md` 中的六项文风规范
- 使用引用编号 `[N]` 标注来源，编号与 `collected_info.md` 一致
- 章节长度控制在字数预算的 ±20% 范围内
- 注意段落间的过渡逻辑

**保存**：
写入独立文件，命名格式为 `report_章节关键词.md`，例如：
- `report_文献综述.md`
- `report_方法论.md`
- `report_结果分析.md`

**生成压缩摘要**：
将该章节的核心信息压缩为200字以内的摘要，包含：
- **核心论点**：一句话概括
- **关键引用**：该章节使用的引用编号列表
- **关键结论**：一句话概括
- **过渡方向**：下一章节应从何处衔接

**更新写作日志**：
读取当前的 `_writing_log.md`，追加新章节的摘要，然后写回。

---

### 3c. 写作包装章

所有核心论述章完成后：

1. 读取 `_writing_log.md` 获取所有核心章节的压缩摘要
2. 逐章写作引言和结论，确保与核心章节的论述一致
3. 分别保存为 `report_引言.md`、`report_结论.md`

---

### 3d. 组装全文

使用 Bash 命令按正确章节顺序拼接所有文件为 `report.md`：

```
cat report_引言.md report_文献综述.md report_方法论.md ... report_结论.md > report.md
```

---
