# SVG 质量校验清单

每个 SVG 生成后，必须逐条对照以下清单检查。所有项通过后方可插入 report.md。

---

## 一、文件完整性

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1.1 | 文件可打开 | SVG 文件能在浏览器中正常渲染，无 XML 解析错误 |
| 1.2 | xmlns 声明 | `<svg xmlns="http://www.w3.org/2000/svg"` 存在且正确 |
| 1.3 | viewBox 正确 | viewBox 值与设计尺寸匹配，内容未被裁切 |
| 1.4 | 文件名规范 | 格式 `img_0N_英文描述.svg`，如 `img_01_architecture_overview.svg` |

## 二、文字与可读性

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 2.1 | 文字不溢出 | 每个 `<text>` 内容宽度 ≤ 所在容器 `<rect>` 宽度。长文本已拆分为 `<tspan>` |
| 2.2 | 字体后备链 | 所有 `<text>` 必须设置 `font-family="Arial, Helvetica, sans-serif"` |
| 2.3 | 字体大小可读 | 最小字号 ≥ 10px。标注文字最小可到 9px，但需确保可辨认 |
| 2.4 | 中英文混排正常 | 中文文字无乱码，英文单词无意外换行 |
| 2.5 | 字号层级一致 | 同一层级（标题/正文/标注）全文字号统一 |

## 三、视觉与配色

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 3.1 | 配色遵循模板 | 使用的颜色来自所选模板的色板，无未定义的颜色 |
| 3.2 | 文字对比度 | 深色背景上的文字为白色（#FFFFFF），浅色背景上的文字为深色（#2C3E50 等） |
| 3.3 | 颜色数量控制 | 全图不超过 5 种不同色相（不包含黑白灰） |
| 3.4 | 无冗余装饰 | 无渐变、纹理、图案填充等不必要的装饰元素 |

## 四、结构对齐

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 4.1 | 框体对齐 | 同级框体的 x/y 坐标对齐，间距均匀 |
| 4.2 | 连接线准确 | 箭头/连线从框体的正确边界点出发，指向正确目标点 |
| 4.3 | 图号与标题 | 左上角有 `图X：标题`，格式为 `<text>` 元素 |
| 4.4 | 边界留白 | 内容区域距 SVG 边界至少 20px |

## 五、图-文一致性

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 5.1 | 信息匹配 | 图中核心信息与 `report.md` 中对应段落描述一致 |
| 5.2 | 术语统一 | 图中使用的术语与正文完全一致（无同义词替换） |
| 5.3 | 数据准确 | 图中的数字、比例、时间等数据与正文一致 |

---

## 修复流程

发现未通过项后：

1. 定位到 SVG 中对应的元素
2. 修复具体问题（调整坐标、拆分文字、替换颜色等）
3. 重新检查该条目

所有条目通过后，才能进行下一步。
