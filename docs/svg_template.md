# SVG 学术风格模板

## 使用规则

1. 生成SVG前，根据图片内容选择合适的模板（单色/双色/三色）
2. 在同一篇报告中，相邻的SVG尽量使用不同色系的模板以增加视觉区分度
3. 严格按照模板定义的色号、字号、间距执行
4. 所有模板均使用 `font-family="Arial, Helvetica, sans-serif"`，不引入系统可能缺失的字体

## 通用规范（所有模板必须遵守）

### viewBox 与尺寸

- 宽度统一使用 900，高度根据内容在 300-560 之间选择
- viewBox 格式：`viewBox="0 0 900 [height]"`
- 内容区域左右各留白 30px，顶部留白 20px

### 文字不可溢出

- 每个 `<text>` 必须配合 `<rect>` 宽度使用，确保文字不超出框体
- 框内文字超过框宽时，拆分为多个 `<tspan>` 分行显示
- SVG 生成后，需要人工复核所有文字位置

### 箭头标记定义

所有需要箭头的SVG，统一在 `<defs>` 中定义：

```svg
<defs>
  <marker id="arrow" viewBox="0 0 10 10" refX="10" refY="5"
      markerWidth="6" markerHeight="6" orient="auto">
    <path d="M 0 0 L 10 5 L 0 10 z" fill="#3498DB" />
  </marker>
</defs>
```

箭头颜色需与所在模板的强调色/连接线色一致。

### 阴影（可选）

需要轻微层级感时使用：

```svg
<filter id="shadow" x="-5%" y="-5%" width="115%" height="115%">
  <feDropShadow dx="1" dy="2" stdDeviation="2" flood-opacity="0.1"/>
</filter>
```

### 标题位置

图标题统一放在SVG左上角（x=30, y=30），格式为 `<text x="30" y="30" font-size="18" font-weight="bold">图X：标题文字</text>`。
