# 阶段二：深度信息搜集

## 前置准备

读取 `初步大纲.md` 和 `pre_search.md`（如存在），获取章节结构和关键词列表。

## 搜集配额

按板块分配搜索量：**每个大纲二级板块至少3-5条高质量信息**，总计不少于15条。
避免窄板块硬凑、宽板块遗漏。

## 质量标准

- 来源可靠：学术数据库（arXiv、Google Scholar、IEEE Xplore）优先，其次为官方技术文档、知名机构报告、行业头部企业博客
- 时效要求：80%以上为近3年内发表，经典理论基础可放宽至5-10年
- 类型多样：包含综述、原创研究、数据集说明、开源代码、技术白皮书、行业应用案例
- 内容相关：每条信息必须与大纲中的某一具体板块直接相关

## 每条信息标注格式

```markdown
- **编号**: [1]
- **标题**: ...
- **来源**: ...
- **链接**: ...
- **发布日期**: ...
- **质量评分**: 高/中/参考
- **核心内容摘录**: ...
- **对应大纲章节**: 2.1
```

编号从 [1] 开始顺序分配，写作阶段直接引用此编号。
质量评分用于写作时优先采用"高"质量来源。

## 搜索策略

1. 基于关键词列表和 `pre_search.md`，设计多样化查询语句
2. **引用链扩展**：找到一篇高质量综述后，追踪其参考文献列表中的关键引用
3. 摘录关键段落、数据、图表描述或结论

## 交付物

将搜集结果整理到 `collected_info.md`，按大纲主题分类。内容以信息条目为主，不做大段论述。

## 完成标志

输出 `collected_info.md` 后，**直接进入下一阶段**，不等待用户。
