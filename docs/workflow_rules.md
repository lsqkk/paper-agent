# 六项文风规范（阶段三、五共用）

## 规范条目

### 1. 禁用分点小标题式段落

禁止使用类似以下格式：
> 1. **短期记忆：** 这是指系统能保留最近几条信息……  
> 2. **长期记忆：** 这是指……

应使用连贯的自然段落，论述的转折通过过渡句或段落首句自然引导。

### 2. 细致全面，深度自然

不要只罗列事实。对每个关键概念，要展开其来龙去脉、内在逻辑、与其他概念的关系。
升华处需基于前文自然推演，禁用突兀的"这启发我们……""深刻的是……"等强行拔高句式。

### 3. 首次出现的重要概念加注英文

格式：全称（英文，缩写）。示例："生成对抗网络（Generative Adversarial Network, GAN）"。
之后可只用缩写。

### 4. 拒绝花哨与说教

严禁使用"如同一个精妙的交响乐团……"等比喻。
严禁使用"不是……而是……""并非……而是……"等否定-肯定式说教句式。
直接陈述事实和逻辑。全文不得出现"并非""不是""从不"等以否定引出肯定的论说方式。

### 5. 标题简洁，禁止冒号或破折号

标题内不得出现"：""—""——"等标点。
例如"向量化：从串行到并行"应改为"向量化"或"向量化与并行计算"。

### 6. 句子长度错落有致

主动混合短句（3-8字）、中句（10-20字）和长句（20字以上，可含逗号分句）。
避免每句话长度相似的"AI腔"。可手动朗读检测节奏。

## 附加格式要求

- 全文引号必须使用中文引号（“”），禁止使用英文引号（""）
- 图片使用Markdown替代文本格式：`![图X：标题](img/img_0X_*.svg)`
- 可使用公式（LaTeX格式）、代码块（标明语言）、表格，但必须与文本自然衔接，且每个公式/代码块前应有引出句，后应有解释句
- 参考文献必须真实：所有引用的文献必须在 `collected_info.md` 中有对应来源，或事后补充真实DOI/链接。禁止编造假文献
